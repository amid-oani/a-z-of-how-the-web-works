# A–Z of How the Web Works

A beginner-friendly series explaining what happens
behind the scenes whenever we use the Web.

This is meant to be a comprehensive archive for anyone who's genuinely interested in knowing the full picture of what goes on when using the web.

## About the Series

We use the Web every day.

We visit websites, watch videos, send information,
buy things, make payments, and communicate with people
around the world.

But what actually happens behind the scenes?

This series breaks down the technologies and concepts
that make the Web work — without assuming that you
already know how software engineering works.

## Who Is This For?
This series is for:

- People curious about how the Web works
- Aspiring software developers
- Non-technical people who want to understand the technology
  they use every day
- Developers who want to strengthen their fundamentals
